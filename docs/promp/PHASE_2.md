## Product

Tên tạm thời:

`TikTok LIVE Automation Platform`

## MVP phải hỗ trợ

### Event

- Follow
- Like
- Comment
- Share
- Gift
- Join/viewer nếu khả thi.

### Action

- TTS
- Sound
- Overlay
- Animation
- WebSocket notification.

### Automation

Người dùng có thể tạo:

`Trigger → Conditions → Actions`

Ví dụ:

`Follow → TTS`

`Gift Rose → Sound + TTS + Overlay`

`Comment contains "hello" → TTS`

`Gift value > X → Special animation`
