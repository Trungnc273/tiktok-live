# Prompt 11 — Automation Dashboard

Implement dashboard for managing automation.

## Screens

### Dashboard

- LIVE status
- current viewers
- likes
- comments
- gifts
- recent events.

### Automations

- list
- create
- edit
- enable/disable
- delete
- duplicate.

### Automation Builder

User configures:

```text
WHEN
  event

IF
  conditions

THEN
  actions
```

## UX

Prioritize:

1. Simplicity
2. Speed
3. Clear feedback
4. Low cognitive load.

A non-programmer streamer must be able to create:

`Gift Rose → TTS + Animation`

without writing code.
